Security

Your passcode, passkeys, and session.

Change passcode
This is the 6-digit code you use to log in.
Workspace access password
The fallback password for the box itself (HTTP Basic). It's the lifeline that can always get in — keep it safe.
Passkeys & biometrics
Passkeys let you unlock with Face ID / Touch ID / Windows Hello. They need a secure context, so they work over https:// or localhost — not over plain HTTP to an IP address.
Session
You stay signed in on this device. You'll only be asked for your passcode again after about 30 days without opening PlumiChat — or if you sign out.
System
Restart the PlumiChat server to apply updates after an upgrade or fix. It's back in a few seconds — your conversations and projects are untouched.
Power the Windows PC itself. A restart brings it back on its own — leave the smart plug on. A shut down powers it right off, so afterwards you can safely switch the smart plug off too.

Engine

The Claude engine PlumiChat runs on. There are two, they are separate installs, and updating one does nothing to the other.

Checking…
Update the engine
This never ships anything and never restarts anything. A successful update writes exactly two files — package.json and package-lock.json — into the dev repo at …. The running server keeps the engine it already loaded. To actually activate a bump you still do the human ship flow yourself: commit → push → pull on the live clone → restart the server. (A terminal-CLI update is the exception: it installs in place, and the next terminal you open picks it up.)
The dry run stages the install in a scratch folder, runs a real Haiku turn on the staged engine, and diffs the options PlumiChat passes. Nothing in this repo or the live clone is touched.
